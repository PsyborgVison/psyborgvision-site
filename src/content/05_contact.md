# Contact — `/contact`

> Goal: lower the friction of starting a conversation. Make it clear what to include so first replies are productive.

---

## Section 01 — Hero

```
EYEBROW (mono, green):  // contact

HEADLINE:               Tell me what
                        you have in mind.

SUBHEAD:                I read every inquiry myself. The more you can tell me up front,
                        the faster I can come back with something useful.
```

---

## Section 02 — Contact form

> Formspree-backed. Single column. Mono labels.

```
FORM FIELDS

  Name                  [text input, required]

  Email                 [email input, required]

  What's this about?    [select, required]
                        Options:
                          - Website project
                          - Web app project
                          - Site management / retainer
                          - Custom 3D print
                          - Catalog purchase question
                          - Collaboration / subcontract
                          - Something else

  Tell me about it      [textarea, required, 6 rows]
                        Placeholder: 
                          What you have in mind, when you need it, links to
                          examples or references, and a budget range if you have one.
                          More detail = faster, more useful first reply.

  Budget (optional)     [select]
                          - Under $1k
                          - $1k–$5k
                          - $5k–$15k
                          - $15k+
                          - Not sure / open

  Timeline (optional)   [select]
                          - ASAP
                          - Within a month
                          - 1–3 months out
                          - Just exploring / no rush

  Files (optional)      [file upload, max 25MB, accepts common formats]

BUTTON:                 Send →

POST-SUBMIT MESSAGE:
  Got it. I'll be in touch within 48 hours, usually faster.
  Replies sometimes land in spam — if you don't hear back, check there
  before assuming it didn't go through.
```

## Section 04 — What helps

> Optional but useful. Lowers reply friction. Could be a sidebar or a section after the form.

```
SECTION EYEBROW:        // what to include

HEADING:                For the fastest useful reply, mention…

LIST
  • What you're trying to build or fix
  • A rough timeline (or "no rush")
  • A budget range if you have one
  • Links to anything you like — sites, products, references
  • Anything you specifically don't want
  • Whether you're local to SoCal (matters for 3D print pickup)
```

## Section 05 — Response expectations

```
SECTION EYEBROW:        // response time

PARAGRAPH:
First replies typically within 48 hours, usually faster on weekdays.
Quotes for fully-described projects within 48–72 hours after the first
back-and-forth. Operating from PST (UTC-8).

If you haven't heard back in three business days, the email may have
gotten lost. Resend it or DM @psyborgvision on Instagram.
```
